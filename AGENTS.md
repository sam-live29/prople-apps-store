# User Custom Instructions

- **Planning for Major Changes**: Only create a step-by-step task list and architectural plan before implementing big architectural or feature changes.
- **Direct Execution for Small Corrections**: For small corrections, minor UI adjustments, styling updates, bug fixes, or isolated tweaks, implement them directly without requiring prior plan approval.
- **Idea & Architecture Logging**: Every time an idea or strategy regarding algorithms, scaling, performance optimization, system maintenance, search engine indexing, Google SEO, or chatbot GEO is discussed, systematically document and store it in `.me` files (such as `OPTIMIZATION_AND_SCALING.me`) to track scaling and optimization blueprints.
