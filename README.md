## Overview

**Prople Store** is an independent, consumer-grade multi-platform application store and web store designed to connect independent software developers directly to users worldwide. Built with zero-telemetry principles and meritocratic discovery, Prople Store provides safe, verified downloads across all major desktop, mobile, and web ecosystems.

---

## Supported Platforms & Package Formats

| Platform | Target OS / Runtime | Primary Package Formats |
| :--- | :--- | :--- |
| **Android** | Android 7.0 and up | `.apk` (Standard Package), `.aab` (Android App Bundle) |
| **Apple (iOS / iPadOS)** | iOS 14.0 or later | `.ipa` (iOS App Package for sideloading & enterprise distribution) |
| **Mac (macOS)** | macOS 12.0 Monterey or later | `.dmg` (Apple Disk Image), `.pkg` (macOS Installer), `.zip` |
| **Linux** | Universal Linux | `.deb` (Debian/Ubuntu), `.AppImage` (Universal Portable), `.rpm` (Fedora/RHEL), `.flatpak`, `.tar.gz` |
| **Windows** | Windows 10, 11 (64-bit) | `.exe` (Win32/x64 Executable), `.msi` (Windows Installer), `.msix`, `.appx`, `.zip` |
| **Web Store** | Modern Web Browsers | Installable Progressive Web Apps (`.pwa`), Web applications, and live interactive demos |

## Core Features

- **Direct GitHub Releases Sync**: Ingest verified releases and signed binaries directly from upstream developer repositories.
- **Cryptographic Verification**: Transparent SHA-256 checksums, keystore fingerprints, and authentic developer signatures.
- **Zero Sponsored Injections**: 100% Bayesian weighted rankings with zero paid search auctions or pay-to-play promotions.
- **Rich Structured Data (SEO / GEO)**: Schema.org `@graph` JSON-LD for search engine crawling and AI chatbot knowledge grounding.
- **Independent Developer Console**: 1-click publishing, automated asset separation, and real-time catalog management.
